Deskmate · UI directions

Four complete directions for the board plus Need attention, each on desktop and mobile with a dark/light switch. All use only Paseo theme color tokens, so identity comes from layout, type, and state language. Open one, drag a task, dismiss a reminder.

Projects screen is not mocked; it will inherit the chosen direction. All data is synthetic.

Assigned direction

A · Front desk

Sessions are numbered pigeonholes; a slip sticks out when one needs you. Tasks are lines in a ruled ledger. Overdue gets a rubber stamp.

Risk: the rack takes vertical space even when nothing needs you.

 Impeccable’s pick

B · Strip bay

Air-traffic-control flight strips in bays. A session that needs you is cocked out of the rack; the colored front box carries time and state.

Risk: densest of the four; on narrow bays titles wrap and project names truncate.

 Alternate

C · Line rail

An instrument plate around one off-centre rail. State is the shape of a hairline (doubled, solid, dashed, struck), one type size throughout.

Risk: the line language must be learned (a legend ships with it); columns get narrow on desktop.

 Standard

D · Standard board

Linear / Trello-style kanban with rounded cards, status pills, and a Needs attention strip on top.

Risk: looks like every other kanban; least of the “own identity” you asked for.
